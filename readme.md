## 📖 Описание проекта

Проект содержит автоматизированные тесты для API сервиса **Яндекс Самокат**. Тесты покрывают основные функциональные возможности:

- ✅ Создание курьера
- ✅ Авторизация курьера
- ✅ Создание заказа
- ✅ Получение списка заказов
- ✅ Удаление курьера (дополнительно)
- ✅ Принятие заказа (дополнительно)
- ✅ Получение заказа по номеру (дополнительно)

Все тесты независимы, используют уникальные тестовые данные и корректно очищают за собой.
